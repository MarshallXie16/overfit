# OVERFIT intro film (20 s)

A code-rendered motion-graphics intro for the game, made with the `motion-design` skill: one `index.html`
whose `window.seek(t)` paints any frame, rendered frame by frame in headless Chromium and encoded by ffmpeg.
Real screenshots only (`assets/`), closed-form springs (`lib/motion.js`), a 120 BPM grid, synthesized score
and SFX. Shot list: `docs/shotlist.md`. Style: `docs/style_guide.md`. Critique rounds: `docs/review_log.md`.

## Render

```bash
npm install                                   # playwright
npx playwright install chromium
node scripts/render.mjs --width 1080 --height 1920 --out out/9x16.mp4     # 60 fps, 4 subframes, CRF 16
node scripts/render.mjs --width 1920 --height 1080 --out out/16x9.mp4
node scripts/score.mjs --bpm 120 --dur 20 --key A --mode minor --out out/score.wav
node scripts/sfx.mjs cues.json out/sfx.wav
scripts/mix.sh out/9x16.mp4 out/final-9x16.mp4 out/score.wav out/sfx.wav --sfx-gain 0.8
scripts/mix.sh out/16x9.mp4 out/final-16x9.mp4 out/score.wav out/sfx.wav --sfx-gain 0.8
```

Drafts for the critique loop: `node scripts/render.mjs --fps 30 --sub 1 --width 540 --height 960 --out out/draft.mp4`
then `scripts/contact_sheet.sh out/draft.mp4 out/rN --at <second>`. Checks: `node scripts/grid_check.mjs beats.json
cues.json --page index.html` and `scripts/determinism_check.sh index.html 20`. `out/` is gitignored; the finals,
poster and contact sheets are regenerated by the commands above. Open `index.html` in a browser for a live preview.
